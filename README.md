# Kirthana P — Portfolio

> Data storyteller & AI creator turning complex ideas into clear stories, useful tools, and memorable experiences.

## 🚀 Overview

Personal portfolio showcasing machine learning studies, interactive simulators, data analytics projects, and engineering toolkits.

### Featured Projects
- **01 · Immersive CPR Training System**: Responsive CPR simulation built in Unity 3D & C#.
- **02 · Credit Rating Classification**: Machine learning risk model using Logistic Regression, Random Forest, XGBoost & SMOTE.
- **03 · Fraud Detection**: Interpretable fraud detection workflow with feature encoding and Scikit-learn.

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS / Vanilla CSS, Lucide Icons
- **Data & AI Tools**: Python, Pandas, Scikit-learn, XGBoost, Power BI, Tableau, SQL

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
